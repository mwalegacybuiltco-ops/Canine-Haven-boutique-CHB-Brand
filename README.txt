CANINE HAVEN BOUTIQUE — BRAND-ONLY BUILD

This build is designed to stop the image headaches:
- Login/brand images load from /assets/brand/
- Shop shows 6 placeholder cards until you add products
- Affiliate share links work on GitHub Pages once Pages is enabled

REQUIRED FOLDER STRUCTURE:
/index.html
/assets.js
/products.js
/config.js
/assets/brand/login.png
/assets/brand/crest.jpeg
/assets/products/   (put product images here later)

If images don't show, 99% of the time it's because the files are NOT inside these folders,
OR the filename (capitalization) doesn't match exactly.
